01

Product List "Termékek" tab home · grid by default · 6 categories

— Termékek tab

The catalogue's front door. iOS large title with search and filter actions in the nav, a sticky search field with a grid/list view toggle on its right, and horizontally-scrollable category chips beneath. Default view is a 2-column grid because product recognition is faster from imagery than text — list mode is one tap away when scanning by price. Long-press any tile to fast-add it to a list.

Chart spec

x-axis
time, evenly-spaced samples (no scale gaps); labels on first / last only to avoid crowding
y-axis
auto-scaled to [min, max] with 8 pt padding; min & max printed top-left / bottom-left in mono caption
line
2 px, round joins; 4 pt dot on the latest sample, 2.5 pt on the rest
fill
10% opacity area under the line in trend color
trend
green #16A34A if last < first · red #DC2626 if last > first
tooltip
tap on a dot → caption: 2026.04.18 · 335 Ft · OCR

03

Product Add full-screen form · sticky save · grouped cards

— Add flow

Distinct from the half-sheet quick-add inside a list — this is the canonical "create a product in the catalogue" surface. Four grouped cards keep the form scannable: Alapadatok, Bolt és ár, Azonosítók (with an inline barcode-scan launcher), and an optional Kép card. The save action lives in the nav-bar text button and a sticky bottom CTA so thumbs and eyes both have a path home.

Field rules

  • Required — Termék neve, Kategória, Egység (red * in label)
  • Validation — name ≥ 2 chars; price numeric, ≥ 0; barcode 8/12/13 digits accepted
  • Inline error — appears 250 ms after blur, never while typing
  • Save state — disabled (40% opacity) until required fields are filled · loading spinner once tapped, button width-locked

Barcode scanner

  • Tap the camera tile → full-screen scanner sheet (modal)
  • On hit → autofill barcode + lookup attempt; if known: prefill all known fields, show "Találat: Tej 2,8%" toast
  • If unknown: barcode only is filled, focus jumps to "Termék neve"
  • Permission denied → toast "Engedélyezd a kamera-hozzáférést a Beállításokban"
SavingBoth Save buttons spinner + locked width. Form fields disabled (60% opacity).

DuplicateIf name + brand match an existing product: warning row at top "Már létezik — szerkeszteni szeretnéd?" · link to that product.
04

Price Overview "Árak" tab · personal inflation · price-change feed

— Árak tab

The dashboard. Period segmented control under the large title (7 / 30 / 90 days) drives every number on the page. Three KPI cards scroll horizontally. The Személyes infláció card is the centerpiece — a donut by category with the headline percentage in the middle, color-coded (red ↑, green ↓). Underneath, a chronological list of price changes with up/down filters. Tap any row to drill into that product's history.
