01

Button 4 variants × 3 sizes × 4 states

— Primary action surface

The button is the system's most-touched primitive. Pressed darkens the fill 10%, disabled drops opacity to 40%, loading swaps the label for a spinner while keeping width fixed (no layout shift). Icon-only square variants honor the 44pt minimum tap area regardless of size token.

Sizes
  • sm — 36 pt · 13 pt · pad 12/16
  • md — 44 pt · 15 pt · pad 14/20
  • lg — 50 pt · 17 pt · pad 16/24
Variants
  • primary — bg primary, fg #FFF
  • secondary — bg #F1F5F9, fg #0F172A
  • ghost — transparent, fg primary
  • destructive — bg #EF4444, fg #FFF
States
  • pressed — fill ×0.9 (10% darker)
  • disabled — opacity 0.4, no haptic
  • loading — spinner, label hidden, width locked
  • Press animation: 80 ms scale 0.97 ease-out

02

Input 4 types × 4 states · label-on-top

— Text capture

Label sits above the field — never floating, never inside — so it stays readable when the keyboard is up and the field is short. Currency uses a right-aligned Ft suffix; search uses leading magnifier + trailing clear when there's a value. Focus animates the border to primary in 120 ms.

Anatomy
  • Label — body-sm 13pt · #475569
  • Field — h 44 pt · radius 10 pt
  • Helper — body-sm 13pt · #64748B
  • Error — body-sm 13pt · #EF4444
Border colors
  • default — #E2E8F0 / dark #334155
  • focused — #2563EB · 1.5 px · 120 ms
  • error — #EF4444 · 1.5 px
  • disabled — #E2E8F0 + bg #F8FAFC
Keyboard hints
  • text — default
  • number — numeric pad
  • currency — numeric, suffix "Ft"
  • search — search return key

05

Checkbox list · bolt-mode

— Selection

Two sizes for two contexts. The 24 pt list checkbox is hairline-bordered when empty, fills with primary blue and a white check when selected; the parent label strikes through and dims to muted. The 56 pt bolt-mode variant goes full-fill (no border state) — at arm's length you read shape, not stroke. Toggle animation: 150 ms ease-out for list, 220 ms spring with 1.08 overshoot for bolt + medium haptic.

Skeleton Loader card · list-row

— Loading

Skeletons mirror the geometry of the content they replace — same radius, same row height, same column count. A 1200 ms left→right shimmer pass at 35% opacity provides liveness without distraction. Never show a skeleton for less than 200 ms; if data lands faster, skip straight to the rendered state.

09

Toast success · error · info

— Transient feedback

A single toast at a time, 16 pt from the bottom safe area, full width minus 16 pt margins. Spring entry (240 ms, damping 0.78), 2800 ms hold, 200 ms slide-out. Colored 4 pt left border keys the variant; dismiss-X always present for power users. Stacking is forbidden — newer toasts replace older ones with a 120 ms cross-fade.

10

Composition rules how primitives stack

— Reminders
Do
  • Use one primary button per screen — it's the lighthouse.
  • Pair Toast + Skeleton: skeleton during load → toast on success / error.
  • Use category Badges as the only color in monochrome lists.
  • Honor 44 pt min tap target — even when visual is smaller (checkbox).
  • Bolt-mode checkboxes ship medium haptic on tap. Always.
Don't
  • Stack toasts — the second one replaces the first via cross-fade.
  • Mix ghost + secondary in the same row — pick one.
  • Use destructive variant for "Cancel" — it's reserved for delete/remove only.
  • Float labels inside inputs. Always above. Hungarian compounds get long.
  • Show a skeleton for less than 200 ms — it'll flicker.
