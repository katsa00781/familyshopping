07

Notes & resolved conflicts changes from the original brief

— Recommendations

Three small adjustments I'd recommend

  • FAB radius `full`, not `28 pt`. The brief specifies both, but `full` is the source of truth — `28 pt` only happens to equal half of a 56 pt FAB. Codifying `full` keeps the radius correct if FAB size ever changes (e.g. 64 pt for one-handed reach).
  • Add `--muted-foreground` for dark mode (`#94A3B8`). The brief lists `muted: #64748B` for dark, which is too low-contrast for placeholder text on `#0F172A` (only 3.4:1 — fails WCAG AA for body). Use `#64748B` for borders/dividers in dark, and a lighter `#94A3B8` for actual muted text.
  • Bolt mode background should stay `#000000` even in light mode. The brief implies bolt = dark variant, but the context (bright supermarket, glare) means we always want pure black, regardless of system theme. Treat bolt as its own surface, not a dark-mode dependency.
  • One token-level conflict resolved: `secondary` (`#F1F5F9`) and `card` (`#FFFFFF`) overlap visually if used adjacent. Reserve `secondary` for filled buttons and inline pill backgrounds; use `card` for floating surfaces only.
